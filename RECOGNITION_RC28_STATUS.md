# RC28 — Multi-photo Review integration

Implemented: accessible per-book photo inputs for front/back/title page; in-memory image selection (no localStorage persistence); resize to JPEG before sending; 2–3 image server fusion via existing authenticated endpoint; checksum validation via fusion module; explicit conflict refusal; confirmation before applying suggestions to empty fields; per-card cancellation with AbortController; per-card progress text; existing OCR, crop, edit and manual approval preserved. Automated regression tests: 253/253 passing.

Limitations: This is **not** a fully completed production-grade recognition system. The endpoint processes providers sequentially within one HTTP request, so cancellation is client-side and does not reliably stop upstream provider usage. No server-controlled durable queue, genuine job progress or retry history is wired to the existing recognition_jobs table. Confidence evidence is agreement count, **not calibrated probability**. Fused suggestions are **not** independently verified against trusted catalogue sources. No real-provider, authenticated browser, mobile, privacy/retention or deployment verification was performed. Images are sent to configured AI providers after explicit user action; review provider terms and retention before production. Auto-approval must remain disabled.
